# hadamard-b-formal

Lean 4 / Mathlib formalization of the bordered Goethals–Seidel theorems of Hadamard-B (Theorem A, the s ≤ 1 layer, Theorem D); Palomar submission in preparation.

Toolchain: `leanprover/lean4:v4.33.0` (frozen; `lake-manifest.json` pins mathlib at `db584cd6d46c92f209a44c0f1c829460d327499d`).

Build: `lake exe cache get && lake build`
